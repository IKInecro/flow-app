# Surface brief — MarcoFlow app shell, hub, editor

Mode: Operate. Desktop-first web app; below 768px the gate explains the desktop requirement.

## Audience and job

Students and teachers arrange an algorithm as a flowchart, run it step by step, and read the generated code. The shell must make the current project, canvas, run state, console, and output readable at a glance without teaching the interface.

## Chosen direction

Campus wayfinding in daylight. The product is a route map for logic: ink navy rail, warm paper work surface, vermilion active route, and line-colour state cues. Familiar product controls stay standard; the world enters through type, palette, density, and one signature move — a live route pulse travelling the active connector while the program runs.

## Direction contract

THESIS: A calm, daylight campus wayfinding system for logic; it refuses the dark terminal with a single neon accent.

OWN-WORLD: Warm porcelain surfaces, ink-navy rail, vermilion active route, cobalt/teal/amber line inks, Bricolage display over Onest UI, JetBrains for code, rounded station plaques and soft offset shadows.

STORY: The visitor sees their projects as routes, opens one into a canvas that behaves like a line map, runs it, and watches the active station and connector pulse while the console narrates the trip.
